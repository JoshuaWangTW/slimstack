# Brand Review — 品牌稽核

檢查對外內容是否符合品牌標準。

## 品牌參照來源

稽核標準讀使用者指定的品牌指南檔案（例如 `references/brand-guide.md`）。首次使用時詢問路徑。該檔未填的項目不憑印象稽核，標「無參照標準，待補」。

## 檢查面向

### 1. 語調一致性
- 用語是否符合品牌定位？（專業/親切/技術）
- 有沒有語氣不一致的段落？
- 行動呼籲（CTA）是否清楚？

### 2. 視覺一致性
- 色彩是否符合品牌色？
- 字體層級是否一致？
- 間距和排版是否整潔？

### 3. 受眾適配
- 內容的深度是否符合目標受眾？
- 有沒有業內術語需要解釋？
- 內容長度是否適合發布平台？

### 4. 事實正確性
- 數據和宣稱有依據嗎？
- 有沒有過度承諾？
- 聯絡資訊和連結正確嗎？

## 輸出

```
## 品牌稽核結果
### 通過 ✅
- [列出沒問題的項目]
### 需修改 ⚠️
- [具體問題與修改建議]
### 整體評語
[一段話總結]
```

稽核通過 ≠ 可發布；實際對外發布仍需使用者確認。

---

## Compact Version

**檢查**：語調一致性 → 視覺一致性 → 受眾適配 → 事實正確性

**輸出**：✅通過 / ⚠️需修改（具體問題+建議）/ 整體評語

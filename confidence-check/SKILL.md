# Confidence Check — 信心度評估

在執行重大操作前，先評估四個維度的準備程度。

## 四個問題

1. **理解程度**：我真的理解這段程式碼/這個系統在做什麼嗎？
   - 能不能用一句話解釋？
   - 有沒有我沒讀過但應該讀的部分？

2. **影響範圍**：這個改動會影響多大範圍？
   - 只影響這個檔案？這個模組？還是整個系統？
   - 有沒有其他地方也用到我要改的東西？

3. **回復能力**：如果改壞了，能多快恢復？
   - 有沒有備份/之前的版本？
   - 這個操作可逆嗎？

4. **驗證方式**：改完之後怎麼確認改對了？
   - 有測試嗎？
   - 可以在 staging 環境先試嗎？

## 評分

每個維度 0-25 分，總分 0-100：
- **≥ 70 分**：可以執行，但注意低分項目
- **< 70 分**：暫停。先補齊低分維度再繼續
- **< 40 分**：強烈建議先做更多研究或拆解問題

## 輸出

```
## 信心度評估
| 維度 | 分數 | 說明 |
|---|---|---|
| 理解程度 | /25 | ... |
| 影響範圍 | /25 | ... |
| 回復能力 | /25 | ... |
| 驗證方式 | /25 | ... |
| **總分** | **/100** | |

建議：[執行 / 暫停並補齊 X]
```

---

## Compact Version

**四維評估**（各 0-25 分）：理解程度 / 影響範圍 / 回復能力 / 驗證方式

**≥70**：執行 | **<70**：暫停補齊 | **<40**：需更多研究
